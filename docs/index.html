Nanobtw Farmer — descargas

Instaladores de Windows y aviso firmado de actualizaciones. El código fuente no se publica aquí.

Descargar

Las versiones se publican en GitHub Releases. Versión actual: 0.2.1.

Antes de instalar

Comprueba que el SHA-256 coincide con el publicado en la página de la versión:

Get-FileHash .\NanobtwFarmer-X.Y.Z-setup.exe -Algorithm SHA256

El instalador no está firmado con un certificado de Windows: pueden aparecer alertas. Si aparece alguna, detente y no desactives ninguna protección.

Actualizaciones

La app instalada lee stable/update.json de este sitio. Va firmado con la clave Ed25519 nbf-2026-1 (clave pública); nada se instala sin tu permiso. Detalles en el README.
